Dirty CLI

A powerful, lightweight CLI tool and AI Agent Sandbox system optimized for Termux and Linux.

Quick Installation

Run the following command to download and run the automated installer:

curl -fsSL https://sheikhcoders.github.io/dirty-cli/installer.sh | bash

What's Included?

  • Dirty CLI: Zero-dependency interface for model setup and edge services.
  • Edge Services: CI/CD and Data Analysis running on Cloudflare Workers.
  • AI Agent Sandbox: Containerized Ubuntu environment with VNC/NoVNC support.
  • Termux Optimized: Specific support for X11, VNC, and graphical output on Android.
